    Add the gate to CI example configuration

    The same scan as a GitHub Action (inputs from action.yml): fails the build on blocking findings, uploads SARIF to the Security tab and writes a CycloneDX SBOM. Exit codes: 0 pass · 1 blocking findings · 2 incomplete scan. After a scan, the live gate decision for that project appears with the results.

    on: [pull_request, push]
permissions: { contents: read, security-events: write }
jobs:
  tracii:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: RaghavAror/TRACII_teamMOM_project@main
        with:
          fail-on: high            # critical | high | medium | low | none
          mode: enforce            # observe = report only
          sbom-file: sbom.cdx.json

    Locally: python -m tracii scan --dir my-app --fail-on high --sarif tracii.sarif --sbom sbom.cdx.json
